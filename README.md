# Bhavesh Mottelwar — Career Portfolio

A separate career portfolio for Bhavesh Mottelwar. The redesign uses a warm editorial palette, oversized type and custom record artwork to make his music identity clear immediately, then gives selected releases, credited production work, listening, career history and contact information a concise path through the page.

The artist website, bhaveshhh.in, remains separate and unchanged. Facts and links on this page come from its published music, portfolio, about and résumé content. The credited-project section explicitly preserves the source portfolio's use of “Kairo.”

## Local preview

Run `node preview-server.js` from this folder, then open <http://127.0.0.1:4174>.

The page is built with HTML, CSS and a small JavaScript file for the mobile navigation. The Spotify embed and external listening links need an internet connection.
